# Gokulavasan M — Portfolio Website

Personal portfolio for **Gokulavasan M**(myself😁😁), an aspiring Software and AI Engineer (B.Tech IT, Class of 2029) from Puducherry, India. Built with semantic HTML, CSS, and JavaScript.

## Sections
* **Hero (myself😁) (`#home`)** — Full-bleed dark editorial intro with portrait backdrop and adaptive top navigation bar
* **About (`#about`)** — Background, academic focus, and staggered reveal text
* **Work (`#work`)** — Horizontally scrollable showcase of projects (*SAGE AI*, *DoubtSense*, *Student System*, *Simple Python Debugger*) with hover/touch states
* **Stack (`#stack`)** — Languages, web & backend, databases, and tools
* **Journey (`#journey`)** — Competitions, presentations, education timeline, and learning highlights
* **Beyond (`#beyond`)** — Personal interests and reflections
* **Connect & Outro (`#connect`, `#outro`)** — Contact links, social profiles, closing quote, and back-to-top navigation

## Project Structure
* `index.html` — Page structure and section content
* `styles.css` — Layout, typography, responsive rules, and animations
* `script.js` — Scroll progress, topbar state toggle, intersection observers, horizontal project scroll, and motion controls
* `assets/` — Visual media assets (such as `gokul-portrait.png`)
